# PayGuard AI - ML Engine

Machine Learning module for fraud detection and risk scoring in PayGuard AI.

## Directory Layout
- `data/`: Dataset storage for raw and processed synthetic data
- `models/`: Trained model serialization files (`.joblib`)
- `src/`: Core Python modules for data generation, model training, prediction, scoring, and explainability

## Dependencies
- pandas
- numpy
- scikit-learn
- joblib
