# PayGuard AI — Resume Project Entry

## Project Title
**PayGuard AI — AI-Powered Payment Fraud Detection & Risk Intelligence Platform**

## Technologies Used
`Python` • `FastAPI` • `React 18` • `SQLAlchemy` • `Scikit-Learn` • `Random Forest` • `Razorpay SDK` • `PostgreSQL` • `Docker` • `Tailwind CSS`

---

## Resume Bullet Points

- **Architected Real-Time Payment Risk Engine**: Developed an AI-powered payment fraud detection platform processing 50,000 synthetic transaction records using FastAPI, React 18, and Scikit-Learn.
- **Trained & Evaluated ML Classifier**: Benchmark-evaluated Logistic Regression, Random Forest, and Gradient Boosting algorithms; deployed a Random Forest fraud classifier achieving **96.58% F1-Score** and **0.9915 PR-AUC**.
- **Engineered Calibrated Risk Scoring & Grounded Explainability**: Implemented a 0–100 risk score engine enforcing automated decisions (`ALLOW`, `REVIEW`, `BLOCK`) and dynamic detection of 11 explainable threat factor codes (velocity spikes, device/IP anomalies, ATO signals).
- **Integrated Razorpay Test Mode & Server-Side Security**: Integrated server-side Razorpay order creation and HMAC-SHA256 signature verification with zero sensitive credential exposure, automated security alert deduplication, and full analyst triage lifecycle management.
